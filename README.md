# EduPulse – Feedback Intelligence System 🎓

EduPulse is a smart student feedback analysis system designed to detect learning difficulties and provide meaningful insights using AI-based sentiment analysis.

## 🚀 Features

- 🧑‍🎓 Student Feedback Submission Portal  
- 👨‍🏫 Staff Dashboard with Feedback Insights  
- 🤖 AI-Based Sentiment Analysis (Positive / Neutral / Improvement Needed)  
- 📊 Visual Dashboard with Ratings & Metrics  
- 🏫 Department & Class-based Filtering  
- ⚙️ Admin Portal for Managing:
  - Departments
  - Subjects
  - Staff
  - Class Years

## 💡 Key Highlights

- Realistic academic structure (Departments, Years, Subjects)
- Safe and professional feedback generation
- No harsh or offensive comments
- Designed for real-world institutional usage

## 🛠️ Tech Used

- HTML
- CSS
- JavaScript

## 📌 Use Case

Helps institutions:
- Identify student learning difficulties  
- Improve teaching quality  
- Analyze feedback trends efficiently
