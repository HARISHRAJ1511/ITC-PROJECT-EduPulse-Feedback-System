# 🚀 EduPulse – Feedback Intelligence System 🎓

EduPulse is an **AI-powered student feedback analysis system** designed to detect learning difficulties and provide meaningful insights using sentiment analysis.

## 🚀 Features  

- 🧑‍🎓 Student Feedback Submission Portal  
- 👨‍🏫 Staff Dashboard with Feedback Insights  
- 🤖 AI-Based Sentiment Analysis (Positive / Neutral / Needs Improvement)  
- 📊 Interactive Dashboard with Ratings & Metrics  
- 🏫 Department & Class-based Filtering  
- ⚙️ Admin Portal for Managing:
  - Departments  
  - Subjects  
  - Staff  
  - Class Years  

---

## 💡 Key Highlights  

- 🎯 Realistic academic system structure  
- 🔒 Safe & professional feedback generation  
- 🚫 No offensive or harmful responses
